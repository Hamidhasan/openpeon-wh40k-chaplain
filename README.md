# Warhammer 40,000: Dawn of War — Chaplain Sound Pack

[![License: CC BY-NC 4.0](https://img.shields.io/badge/License-CC_BY--NC_4.0-lightgrey.svg)](https://creativecommons.org/licenses/by-nc/4.0/)

A sound pack for [peon-ping](https://github.com/PeonPing/peon-ping) featuring voice lines from the **Space Marine Chaplain** unit in *Warhammer 40,000: Dawn of War*.

When your CLI agent fires events — task complete, errors, approvals — the Chaplain delivers the Emperor's judgement.

## Install

```bash
peon packs install wh40k-dow-chaplain
peon packs use wh40k-dow-chaplain
```
